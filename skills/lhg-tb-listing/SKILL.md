# lhg-tb-listing：上架与单品优化

## 1. 何时使用

- 新品上架，需要一套标题/主图/详情页一次做对的流程时
- 老链接没流量，怀疑标题或主图有问题时
- 详情页转化率低，想按买家决策顺序重排时

**前置**：品已选定（`lhg-tb-select`）。全程叠加 `lhg-tb-compliance` 合规红线。

## 2. 输入与输出

**输入**：产品信息（品名、卖点 3-5 条、目标人群、成本价）。

**输出**：单品资产包——`标题.txt`、`主图.md`、`sku.md`、`详情.md`、`价格.md`。

## 3. 分步方法论

### 第 1 步：标题（30 字公式）

公式：**品类词 + 属性词 + 卖点词**，核心词前置。

- 字数：≤30 个汉字，超了会被截断
- 合规：无极限词（最/第一/首家/顶级）、无违禁词（假一赔十/原单/高仿）
- 格式：空格 ≤10 个，特殊符号（★⚡）≤4 个
- 好例子："ins风陶瓷马克杯带盖勺400ml办公室水杯"
- 坏例子："2026最畅销第一名顶级神器"（极限词+符号堆砌，下架预定）

### 第 2 步：主图五张（每张回答一个购买理由）

| 张 | 任务 | 检查点 |
|---|---|---|
| 1 | 白底首图 | 800×800，产品主体清晰、无牛皮癣 |
| 2 | 场景图 | 讲清"在哪用" |
| 3 | 卖点图 | 讲清"为什么买你" |
| 4 | 细节图 | 讲清"质量凭什么" |
| 5 | 套装/服务图 | 讲清"买到什么+售后" |

- 图文必须一致，不许夸大（效果图与实物差距大=退货预定）
- 文案先审再出图，卖点取舍、顺序确认后再执行

### 第 3 步：SKU（属性+利润双齐全）

- 关键属性：颜色/尺码/规格/款式，缺一不可（缺属性=退货率飙升）
- 每个 SKU 标注：成本价、售价、毛利（不算账就定价，活动一打折就亏）

### 第 4 步：详情页（按买家决策顺序排屏）

顺序：头图 → 痛点 → 卖点 → 展示 → 细节 → 参数表 → 实拍图 → 尺码表 → 场景 → 对比 → 资质 → 品牌 → 服务 → 售后保障。

- 必备模块：参数表、实拍图、尺码表、售后说明（至少命中 2 个）
- 红线：无承诺性用语（假一赔十/百分百正品）

### 第 5 步：价格标注

`价格.md` 写清：成本价、定价策略、毛利率。**先算账再定价**，这是铁律。

## 4. 人工评审清单（脚本抓不到的）

1. 标题读起来顺不顺？→ 关键词堆砌读不顺就重组
2. 主图每张的购买理由清不清晰？→ 一张图讲两件事就拆
3. 详情页图文一致吗？→ 不一致就改图或改文案
4. 价格有利润吗？→ 没利润的上架就是做慈善

## 5. 反模式

- ❌ 标题 30 字塞满关键词——读不顺，点击率低
- ❌ 主图用网图/盗图——侵权下架，赔钱又丢店
- ❌ SKU 不分颜色尺码——买家选错，退货率爆炸
- ❌ 详情页只有美图没有参数——买家想看的你没给
- ❌ 不算账就定价——活动一报名就亏

## 6. 完整示例：单品资产包（陶瓷马克杯）

**标题.txt**：

```
ins风陶瓷马克杯带盖勺400ml办公室水杯
```

（14 个汉字，品类词"马克杯/水杯"+属性词"陶瓷/400ml/带盖勺"+卖点词"ins风/办公室"，无极限词违禁词）

**主图.md**：

```markdown
# 主图规划：陶瓷马克杯
尺寸规范：800×800。
- 第 1 张（白底首图）：产品正面，主体清晰
- 第 2 张（场景图）：办公室桌面，讲清"在哪用"
- 第 3 张（卖点图）：盖勺细节，讲清"为什么买你"
- 第 4 张（细节图）：杯口工艺特写，讲清"质量凭什么"
- 第 5 张（套装图）：礼盒装+售后说明，讲清"买到什么"
```

**sku.md**：颜色（白/粉/蓝）、尺码（400ml）；成本 12 元、售价 29.9 元、毛利约 50%。

**详情.md**：按"参数表→实拍图→尺码表→售后说明"排屏；售后：7 天退换，赠运费险。

**价格.md**：成本价 12 元；定价策略：锚定 29.9 元，对标同类中端；毛利率约 60%。

## 7. 上架前检查清单（10 条，逐条打勾）

- [ ] 标题 ≤30 汉字，核心词前置
- [ ] 标题无极限词/违禁词
- [ ] 标题空格 ≤10 个，特殊符号 ≤4 个
- [ ] 主图 5 张齐全，800×800
- [ ] 首图白底，产品主体清晰
- [ ] 每张主图只讲一个购买理由
- [ ] SKU 关键属性齐全（颜色/尺码等）
- [ ] 每个 SKU 标注成本/售价/毛利
- [ ] 详情页必备模块 ≥2 个，无承诺性用语
- [ ] 价格.md 写清成本价、定价策略、毛利率
- [ ] 全包跑一遍审计脚本，blocker 清零

**清单使用纪律**：10 条全勾才能上架；勾不上的写豁免理由+整改时间，不许"下次一定"。

## 8. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 资产包 5 件齐了吗？→ 缺一件就是半成品。
2. 合规红线扫了吗？→ 极限词/违禁词零容忍。
3. 评审清单 4 条过了吗？→ 没过重写对应部分。
4. 跑审计脚本了吗？→ `taobao_audit.py` blocker 必须清零。

如发现本 skill 自身的方法论缺陷，按以下流程反馈：

- **标准冒烟用例**：拿一个马克杯走一遍本 skill，生成 5 件资产，检查标题公式、主图五张、SKU、详情页模块是否达标。
- **一键提 issue**：确认问题后，以 `[QC] <一句话问题>` 为标题、正文写清"复现输入 → 错误输出 → 期望输出"，提交到 https://github.com/lhg-plugs/lhg-taobao/issues。
