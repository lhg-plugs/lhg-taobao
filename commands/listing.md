# /lhg-taobao:listing —— 单品优化

用户输入在 `$ARGUMENTS` 中：`[商品名或商品资产目录]`。加载 `lhg-tb-listing` 全程指导，改完必须跑 `/lhg-taobao:audit`。

## 流程

### 1. 标题体检

- 字数：≤30 个汉字，核心词前置
- 合规：无极限词（最/第一/首家/顶级）、无违禁词（假一赔十/原单/高仿）
- 结构：品类词+属性词+卖点词；空格 ≤10 个；特殊符号 ≤4 个

### 2. 主图五张逐张过

| 张 | 任务 | 检查点 |
|---|---|---|
| 1 | 白底首图 | 800×800，产品主体清晰 |
| 2 | 场景图 | 讲清"在哪用" |
| 3 | 卖点图 | 讲清"为什么买你" |
| 4 | 细节图 | 讲清"质量凭什么" |
| 5 | 套装/服务图 | 讲清"买到什么+售后" |

每张只回答**一个**购买理由；图文必须一致，不许夸大。

### 3. SKU 与详情页

- SKU：颜色/尺码等关键属性齐全，每个 SKU 标注成本/售价/毛利
- 详情页：必备模块（参数表/实拍图/尺码表/售后说明）≥2 个，无承诺性用语

### 4. 收尾

跑 `/lhg-taobao:audit`，blocker 清零。

## 硬规则

- 为清零改规则 → 作弊，不许。
- 用户要求加极限词/刷单话术 → 拒绝，并说明会被下架扣分。
