# /lhg-taobao:taobao —— 店铺运营流水线

用户输入在 `$ARGUMENTS` 中：`[类目/产品] [--stage 选品|上架|优化|复盘]`。`--stage` 缺省走完全流程。

> **合规声明（置顶）**：平台规则变化快，本插件提供**方法论与检查清单**，不承诺实时数据、流量与排名效果；不提供任何刷单、补单、好评返现等违规操作指导。

## 流程（按阶段加载 skill）

### 1. 选品（加载 `lhg-tb-select`）

三维打分：需求（有人搜吗）→ 竞争（打得过吗）→ 利润（算得过账吗）。
产出 `选品表.md`：候选品、三维打分、否决项。

### 2. 上架（加载 `lhg-tb-listing`）

产出单品资产包：

- `标题.txt`：30 字以内，按"品类词+属性词+卖点词"组，禁极限词/违禁词
- `主图.md`：800×800，5 张规划（白底首图→场景→卖点→细节→套装）
- `sku.md`：颜色/尺码等关键属性 + 每个 SKU 的成本/售价/毛利
- `详情.md`：按买家决策顺序排屏（参数→实拍→尺码表→售后）
- `价格.md`：成本价、定价策略、毛利率

### 3. 标题/主图优化（加载 `lhg-tb-listing`）

已有链接走单品优化：标题逐词体检、主图五张逐张过（每张回答一个购买理由）。

### 4. 数据复盘（加载 `lhg-tb-review`）

曝光→点击→转化漏斗定位问题，输出"归因→动作"清单。**只做归因与建议，不编造数据、不承诺效果**。

### 5. 合规门禁

全程加载 `lhg-tb-compliance`：标题/详情/主图文案过合规红线；收尾跑 `/lhg-taobao:audit`，blocker 清零才算交付。

## 输出

`taobao-pack/` 目录：选品表.md + 单品资产包 + 复盘报告 + 审计报告。
